# Inkling-2-Mini: arch-загрузчик и forward — план

> **For agentic workers:** REQUIRED SUB-SKILL: subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** tokshit грузит Inkling-2-Mini GGUF (`general.architecture=inkling2`) и генерирует текст без llama.cpp.

**Architecture:** Model dispatch по arch; отдельный `Inkling2` backend с 24 физическими блоками и 48 KV-слотами; arch-spec резолвер ключей; новые кванты; отдельный токенизаторный pre.

**Tech Stack:** C++20, NEON, существующие Gguf/Tokenizer/AHB/dequant.

**Spec:** `docs/superpowers/specs/2026-11-21-inkling2-arch-loader-design.md`

## Global Constraints

- `.gguf` только read-only; модель 9.14 ГБ в `~/Inkling-2-Mini-GGUF/`.
- Один процесс модели; замеры через `scripts/safe_run.sh`.
- Flint-путь не меняется численно; `build/tokshit_tests` остаётся зелёным.
- Эталон формул: llama.cpp master (`src/models/inkling2.cpp`, `inkling2-loop.cpp`, `src/llama-graph.cpp`).

## Review Focus

- Токен вне словаря → ошибка, не нулевые логиты.
- Q2_0/NVFP4/MXFP4 раскладка: 64/64/32 элементов, little-endian.
- Loop-слоты: физический вес vs свой KV; перепутать = мусор без падения.
- Относительный bias: `extent+1` строк, out-of-range → последняя строка.
- Память: KV 48 слотов; cap 2048 f16 ≈ 402 МБ.
